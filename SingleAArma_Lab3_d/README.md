# Lab 3 — Troubleshooting \& Debugging Exercise



### Objective

The purpose of this lab is to simulate real-world debugging scenarios where engineers must analyze, understand, and fix unfamiliar codebases. The assessment focuses on the problem-solving process rather than just the final outcome.



#### Technical Requirements



* Fork the provided GitHub repository.
* Clone your fork locally.
* Attempt to run the application.
* Identify and troubleshoot:

	Runtime errors

	Syntax errors

	Dependency issues

	Environment mismatches

	Expected Debugging Actions



* Read error messages carefully.
* Modify code incrementally to isolate problems.
* Install missing dependencies as needed.
* Fix:

	Incorrect imports

	Logic errors

	Version mismatches



*Note: The project should not be rewritten entirely. The goal is targeted, minimal fixes that make the code executable.*



#### Troubleshooting Documentation



##### Initial Errors Encountered



1. Runtime error: for a missing dependency.
2. Syntax errors due to outdated code syntax.
3. Environment mismatch causing version incompatibilities.



##### Steps Taken to Diagnose



1. Read the console error messages carefully.
2. Verified Python version and package dependencies.
3. Ran the code incrementally to isolate the lines causing errors.
4. Cross-checked documentation for correct imports and function usage.



##### Code Changes Made



1. Installed missing packages.
2. Corrected syntax errors and outdated function calls.
3. Updated import statements to match the installed package versions.
4. Adjusted environment settings to match expected Python version.



##### Final Results



* Code executes successfully without errors.
* Application produces the expected output.
* All identified issues were resolved incrementally without rewriting the codebase.
